# Site Bookzik

Site statique en français destiné à GitHub Pages.

- `index.html` : accueil
- `confidentialite.html` : politique de confidentialité
- `conditions.html` : conditions d’utilisation
- `style.css` : styles communs
- `assets/logo.png` : logo Bookzik

Publication GitHub : Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

**Avant diffusion définitive :** vérifier les mentions légales, l’identité juridique et les coordonnées requises du responsable du traitement, les bases juridiques et les droits des personnes. Le contenu juridique fourni est une base de travail et non une validation juridique.
